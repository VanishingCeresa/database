Testing non-hyperellipticity

The Ceresa cycle of a hyperelliptic curve vanishes, so the catalogue records only curves proved to be non-hyperelliptic. Throughout, $C$ is a curve of genus $g \ge 3$. Any one of the tests below is enough.

By computer

In Magma, for a curve C given by equations:

IsHyperelliptic(C);               // over the base field of C
IsGeometricallyHyperelliptic(C);  // over an algebraic closure
Genus(C);

The catalogue needs the second one to return false.

By hand

  1. Genus 3. A curve of genus $3$ is non-hyperelliptic exactly when it is isomorphic to a smooth plane quartic.
  2. Canonical map. $C$ is non-hyperelliptic exactly when the canonical map $C \to \mathbb{P}^{g-1}$ is an embedding. For a hyperelliptic curve it has degree $2$ onto a rational normal curve.
  3. Quadrics through the canonical curve. By Max Noether's theorem, $C$ is non-hyperelliptic exactly when $\mathrm{Sym}^2 H^0(C, K_C) \to H^0(C, 2K_C)$ is surjective. Equivalently, the canonical image lies on exactly $\tfrac{(g-2)(g-3)}{2}$ independent quadrics; in the hyperelliptic case it lies on $\tfrac{(g-1)(g-2)}{2}$.
  4. Involutions. The hyperelliptic involution is central in $\mathrm{Aut}(C)$, has $2g+2$ fixed points, and its quotient has genus $0$. So if no involution of $C$ has a quotient of genus $0$, then $C$ is non-hyperelliptic.
  5. Size of the automorphism group. If $|\mathrm{Aut}(C)| > \max\{8(g+1),\, 120\}$, then $C$ is not hyperelliptic [QZ24, Lemma 3.1.1]. In particular, Hurwitz curves are never hyperelliptic [QZ24, Cor. 3.1.2].
  6. Eigenvalues of an automorphism. On a hyperelliptic curve $y^2 = f(x)$, every automorphism acts on the forms $x^i\,dx/y$, for $0 \le i \le g-1$, with eigenvalues $\lambda,\ \lambda\mu,\ \dots,\ \lambda\mu^{g-1}$. So if one automorphism of $C$ acts on $H^0(C, \Omega^1)$ with eigenvalues that do not form a geometric progression, then $C$ is not hyperelliptic. The Python script on the implementation page runs this test.
