Implementation

How to check in practice that $\bigl(\bigwedge^3 H^1(C)\bigr)^G = 0$, so that Laga–Shnidman's criterion (A) applies: first the mathematics, then the code.

General considerations

Let $C$ be a curve of genus $g$ and let $G = \mathrm{Aut}(C)$. Suppose there is a Galois branched cover $\pi\colon C \to C/G = \mathbb{P}^1$ ramified at $0, 1, \infty$. By the Riemann–Hurwitz formula, $$\frac{2g-2}{|G|} = -2 + \Bigl(1 - \frac{1}{e_0}\Bigr) + \Bigl(1 - \frac{1}{e_1}\Bigr) + \Bigl(1 - \frac{1}{e_\infty}\Bigr).$$

Let $V = H^0(C, \Omega^1_C)$, seen as a representation of $G$. For $\star \in \{0, 1, \infty\}$, let $G_\star = \langle a_\star \rangle$ be the inertia group, of order $e_\star$, where $a_\star$ is chosen so that it acts on the cotangent space of $C$ by multiplication by $\zeta_{e_\star} = e^{2 i \pi / e_\star}$. Write $\nu_\star$ for the primitive character of $G_\star$ sending $a_\star$ to $\zeta_{e_\star}$.

Step 1: the character of $V$

For a character $\chi$ of $G$ and $1 \le j \le e_\star$, let $N_{\star, j}(\chi) = \langle \nu_\star^{\,j}, \chi \rangle_{G_\star}$. The Chevalley–Weil formula states that

Theorem (Chevalley–Weil). $$\chi_V = \mathbf{1} - \chi_{\mathbb{C}[G]} + \sum_{\chi \in \mathrm{Irr}(G)} \Bigl[\, \sum_{\star \in \{0,1,\infty\}} \sum_{j=1}^{e_\star - 1} \Bigl(1 - \frac{j}{e_\star}\Bigr) N_{\star, j}(\chi) \Bigr] \cdot \chi .$$

This Magma code computes it. Fill in the group and the generators $a_0$, $a_1$ at the bottom; it prints $\chi_V$ as a sum of rows CT[i] of the character table. Download CharacterOfV.m

// Character of G on V = H^0(C, Omega^1), by the Chevalley-Weil formula,
// for a Galois cover C -> C/G = P^1 branched at 0, 1, infinity.
//
// inertia = [a_0, a_1, a_inf]: generators of the inertia groups, each chosen so
// that it acts on the cotangent space of C by multiplication by exp(2 pi i / e).

function CharacterOfV(G, inertia)
    Irr := CharacterTable(G);
    triv := Position(Irr, CharacterRing(G)!1);
    n    := #Irr;

    function Ninner(chi, g, e, j)
        z := RootOfUnity(e);
        s := &+[ z^(-j*k) * chi(g^k) : k in [0..e-1] ];   // project onto zeta^j eigenspace
        return Rationals()!(s / e);
    end function;

    mult := [ Integers() | ];
    for i in [1..n] do
        chi := Irr[i];
        cc  := -(Rationals()!Degree(chi));   // -chi(C[G])
        if i eq triv then cc +:= 1; end if;  // +1 (trivial)
        for g in inertia do
            e := Order(g);
            for j in [1..e-1] do
                cc +:= (1 - j/e) * Ninner(chi, g, e, j);
            end for;
        end for;
        error if Denominator(cc) ne 1, "not valid cover data";
        Append(~mult, Integers()!cc);
    end for;
    return &+[ mult[i] * Irr[i] : i in [1..n] ], mult;
end function;

procedure DisplayV(m)
    s := "";
    for i in [1..#m] do
        c := m[i];
        if c eq 0 then continue; end if;
        t := (Abs(c) eq 1) select Sprintf("CT[%o]", i)
                 else Sprintf("%o*CT[%o]", Abs(c), i);
        if s eq "" then
            s := (c lt 0) select "-" cat t else t;
        else
            s := s cat ((c lt 0) select " - " else " + ") cat t;
        end if;
    end for;
    printf "chi(V) = %o\n", (s eq "") select "0" else s;
end procedure;

G     := /* your group, e.g. SmallGroup(192, 194) */;
a_0   := /* generator of G_0, e.g. G.1*G.4 */;
a_1   := /* generator of G_1 */;
a_inf := (a_0*a_1)^-1;
CT    := CharacterTable(G);
Order(a_0), Order(a_1), Order(a_inf);   // (e_0, e_1, e_inf)
sub<G | a_0, a_1, a_inf> eq G;          // generation
chiV, m := CharacterOfV(G, [a_0, a_1, a_inf]);
DisplayV(m);                            // chi(V) as a sum of CT[i]

Step 2: invariants in $\bigwedge^3 H^1(C)$

Let $W = H^1(C) = V \oplus V^\vee$. The goal is to find non-hyperelliptic examples where $\bigl(\bigwedge^3 W\bigr)^G = 0$. We use the formula $$\chi_{\wedge^3 W}(g) = \frac{1}{6}\Bigl(\chi_W(g)^3 - 3\,\chi_W(g^2)\,\chi_W(g) + 2\,\chi_W(g^3)\Bigr).$$

To check, put the indices found in step 1 into parts. The code prints the multiplicity of the trivial representation in $\bigwedge^3 W$; if it is $0$, the Ceresa cycle is torsion in the Chow group. Download Wedge3.m

// Multiplicity of the trivial representation in Wedge^3(W), where
// W = H^1(C) = V + dual(V) and V = H^0(C, Omega^1).
// If it is 0, Laga-Shnidman's criterion (A) applies.

// <chi, 1> = 1/|G| * sum_i |C_i| chi(g_i)
function TrivMult(chi, G)
    cc := Classes(G);
    s  := &+[ cc[i][2] * chi[i] : i in [1..#cc] ];
    return s / #G;
end function;

function Wedge3(chi, pm)
    return [ (chi[i]^3 - 3*chi[pm(i,2)]*chi[i] + 2*chi[pm(i,3)]) / 6
             : i in [1..#chi] ];
end function;

// ---- input: any group, and the constituents of chi(V) found by CharacterOfV.m
G     := /* your group, e.g. SmallGroup(192, 194) */;
parts := /* sequence of indices, e.g. [5, 8, 17] */;

CT := CharacterTable(G);
pm := PowerMap(G);

X  := &+[ CT[i] : i in parts ];
W  := X + ComplexConjugate(X);
W3 := Wedge3(W, pm);

mult := TrivMult(W3, G);
printf "Multiplicity of trivial rep in Wedge^3(W): %o\n", mult;

Step 3: check that the curve is not hyperelliptic

The Ceresa cycle of a hyperelliptic curve vanishes for a trivial reason, so this must be ruled out. With an equation for $C$, in Magma:

IsHyperelliptic(C);               // over the base field of C
IsGeometricallyHyperelliptic(C);  // over an algebraic closure

Without an equation, the group is often enough:

Remark. If $|G| > \max\{8(g+1),\, 120\}$, then $C$ is not hyperelliptic. [QZ24, Lemma 3.1.1] More tests are on the page testing non-hyperellipticity.

Worked examples

  • Genus 7. The Fricke–Macbeath curve has $G = \mathrm{SL}_2(\mathbb{F}_8)$ and signature $(2,3,7)$. Take $a_0 = G_1 G_2 G_1 G_2^{-1}$ and $a_1 = G_1 G_2 G_1^{-1}$; then $\chi_V = \chi_2$.
  • Genus 9. The curve 9.192-194.2-3-12 has $G = [192, 194]$ and signature $(2,3,12)$. Take $a_0 = G_1 G_4$, $a_1 = G_2$ and $a_\infty = G_1 G_2^2 G_4$; then $\chi_V = \chi_5 + \chi_8 + \chi_{17}$.

Here $G_i$ are Magma's generators of the group and $\chi_i$ is the $i$-th row of its character table.

Without Magma

The same check can be done without a character table. Describe the cover by a generating vector $(c_1, \dots, c_r)$: elements that generate $G$, with $c_1 \cdots c_r = 1$, where $c_i$ generates the inertia group at a point above the $i$-th branch point and has order $e_i$. For $x\ne1$ in $G$, the fixed points of $x$ above the $i$-th branch point are the cosets $h\langle c_i\rangle$ with $h^{-1}xh = c_i^{\,k}$, and $x$ rotates the tangent space there by $\zeta_{e_i}^{\,k}$. The holomorphic Lefschetz formula then gives $$\chi_V(x) = 1 - \sum_{P\,\in\,\mathrm{Fix}(x)} \frac{1}{1-\overline{\lambda_P}}, \qquad \chi_W(x) = 2 - \#\mathrm{Fix}(x),$$ where $\lambda_P$ is the rotation of $x$ at $P$.

This Python script (no packages needed) takes a generating vector as permutations, with any number of branch points, and returns the genus, $A = \dim\bigl(\bigwedge^3 W\bigr)^G$ for criterion (A), $B = \dim\bigl(\bigwedge^3 V\bigr)^G$ for criterion (B), and whether the eigenvalue test proves that the curve is not hyperelliptic. Download ceresa_check.py

"""
Checks for the Laga-Shnidman criteria, for a curve C with a group action.

Input : a generating vector (c_1, ..., c_r) of a finite group G: permutations
        that generate G and satisfy c_1 * ... * c_r = 1.  They describe the
        curves C with a G-action and C/G = P^1, branched at r points with
        monodromy c_1, ..., c_r.
Output: check(vector) returns
          genus   the genus of C
          A       dim (wedge^3 H^1(C))^G.        A = 0: criterion (A) applies, the Ceresa
                                                 cycle is torsion in the Chow group
          B       dim (wedge^3 H^0(C,Omega^1))^G. B = 0: criterion (B) applies, torsion in the
                                                 Griffiths group, assuming the Hodge conjecture
          nonhyp  True if the test below proves that C is not hyperelliptic

Method.  Let V = H^0(C, Omega^1).  For x != 1 in G, the fixed points of x above the
i-th branch point are the cosets h<c_i> with h^-1 x h = c_i^k, and x rotates the
tangent space there by exp(2 pi i k / e_i).  The holomorphic Lefschetz formula gives
    chi_V(x) = 1 - sum over fixed points of 1 / (1 - conj(rotation)),
and chi_V(1) = g.  Then H^1(C) = V + conj(V), and for any character chi
    dim (wedge^3)^G = 1/|G| * sum_x (chi(x)^3 - 3 chi(x) chi(x^2) + 2 chi(x^3)) / 6.

Non-hyperellipticity.  If C is hyperelliptic, y^2 = f(x), every automorphism s acts on
the forms x^i dx / y (i = 0..g-1) with eigenvalues lambda * mu^i: a geometric progression.
So if some s in G has eigenvalues on V that do not form one, C is not hyperelliptic.

Needs only Python 3.   Run:  python3 ceresa_check.py
A permutation of {0, ..., n-1} is a tuple p, sending i to p[i].
"""
import cmath
from fractions import Fraction
from itertools import product


# ---------------------------------------------------------------- permutations
def mul(p, q):
    """The permutation 'first p, then q'."""
    return tuple(q[i] for i in p)


def inverse(p):
    inv = [0] * len(p)
    for i, j in enumerate(p):
        inv[j] = i
    return tuple(inv)


def power(p, k):
    result = tuple(range(len(p)))
    for _ in range(k):
        result = mul(result, p)
    return result


def order(p):
    identity, q, k = tuple(range(len(p))), p, 1
    while q != identity:
        q, k = mul(q, p), k + 1
    return k


def cycles(n, *cycs):
    """cycles(5, (0, 1, 2), (3, 4)) is the permutation (0 1 2)(3 4) of {0,...,4}."""
    p = list(range(n))
    for cyc in cycs:
        for i, a in enumerate(cyc):
            p[a] = cyc[(i + 1) % len(cyc)]
    return tuple(p)


def group(generators):
    """All elements of the group generated by the given permutations."""
    identity = tuple(range(len(generators[0])))
    elements, frontier = {identity}, [identity]
    while frontier:
        new = []
        for x in frontier:
            for s in generators:
                y = mul(x, s)
                if y not in elements:
                    elements.add(y)
                    new.append(y)
        frontier = new
    return elements


def conjugacy_classes(G):
    """Returns (class_of, representatives, sizes): class_of[x] is the index of the class of x."""
    class_of, reps, sizes = {}, [], []
    inverses = {h: inverse(h) for h in G}
    for x in sorted(G):
        if x in class_of:
            continue
        cls = {mul(mul(inverses[h], x), h) for h in G}
        for y in cls:
            class_of[y] = len(reps)
        reps.append(x)
        sizes.append(len(cls))
    return class_of, reps, sizes


# ---------------------------------------------------------------- the checks
def genus(G, vector):
    """Riemann-Hurwitz: 2g - 2 = |G| (r - 2 - sum 1/order(c_i))."""
    return 1 + len(G) * (len(vector) - 2 - sum(Fraction(1, order(c)) for c in vector)) / 2


def characters(G, vector, classes=None):
    """Class functions (lists indexed by conjugacy class): chi_V (complex) and #Fix (exact)."""
    class_of, reps, sizes = classes or conjugacy_classes(G)
    inverses = {h: inverse(h) for h in G}
    g = genus(G, vector)
    powers = []                                   # for each c_i: {c_i^k: k}
    for c in vector:
        table, q = {}, tuple(range(len(c)))
        for k in range(order(c)):
            table[q] = k
            q = mul(q, c)
        powers.append(table)
    chiV, fix = [], []
    for x in reps:
        if order(x) == 1:
            chiV.append(complex(g)); fix.append(None)
            continue
        value, count = 1 + 0j, Fraction(0)
        conjugates = [mul(mul(inverses[h], x), h) for h in G]
        for table in powers:
            e = len(table)
            for y in conjugates:
                k = table.get(y)
                if k:                                              # y = c_i^k with k != 0
                    count += Fraction(1, e)
                    value -= (1 / (1 - cmath.exp(-2j * cmath.pi * k / e))) / e
        chiV.append(value); fix.append(count)
    return chiV, fix


def wedge3_invariants(chi, G, class_of, reps, sizes):
    total = 0
    for i, x in enumerate(reps):
        x2, x3 = class_of[mul(x, x)], class_of[power(x, 3)]
        total += sizes[i] * (chi[i]**3 - 3 * chi[i] * chi[x2] + 2 * chi[x3]) / 6
    return total / len(G)


def is_geometric_progression(mult, n, g):
    """mult[j] = multiplicity of exp(2 pi i j / n).  Is the multiset {a + i*m mod n : i < g}?"""
    for a in range(n):
        if not mult[a]:
            continue
        for m in range(n):
            seen = [0] * n
            for i in range(g):
                seen[(a + i * m) % n] += 1
            if seen == mult:
                return True
    return False


def proves_nonhyperelliptic(G, chiV, class_of, reps, g):
    for x in reps:
        n = order(x)
        if n == 1:
            continue
        values = [chiV[class_of[power(x, k)]] for k in range(n)]
        mult = [round((sum(values[k] * cmath.exp(-2j * cmath.pi * j * k / n) for k in range(n)) / n).real)
                for j in range(n)]
        if not is_geometric_progression(mult, n, g):
            return True
    return False


def check(vector):
    G = group(list(vector))
    identity = tuple(range(len(vector[0])))
    product_ = identity
    for c in vector:
        product_ = mul(product_, c)
    assert product_ == identity, "the generating vector must have product 1"
    g = genus(G, vector)
    assert g.denominator == 1 and g >= 0, "these orders do not give a curve"
    g = int(g)
    classes = conjugacy_classes(G)
    class_of, reps, sizes = classes
    chiV, fix = characters(G, vector, classes)
    chiW = [Fraction(2 * g) if f is None else 2 - f for f in fix]
    A = wedge3_invariants(chiW, G, *classes)
    B = wedge3_invariants(chiV, G, *classes)
    assert A.denominator == 1 and abs(B - round(B.real)) < 1e-6
    return {"order": len(G), "signature": tuple(order(c) for c in vector), "genus": g,
            "A": int(A), "B": round(B.real),
            "nonhyp": g >= 3 and proves_nonhyperelliptic(G, chiV, class_of, reps, g)}


def generating_vectors(generators, orders):
    """Generating vectors with the given orders, one for each choice of conjugacy classes."""
    G = group(generators)
    class_of, reps, sizes = conjugacy_classes(G)
    by_order = {}
    for x in G:
        by_order.setdefault(order(x), []).append(x)
    seen = set()
    firsts = [x for x in reps if order(x) == orders[0]]
    for a in firsts:
        for middle in product(*[by_order.get(n, []) for n in orders[1:-1]]):
            p = a
            for b in middle:
                p = mul(p, b)
            last = inverse(p)
            if order(last) != orders[-1]:
                continue
            vector = (a,) + middle + (last,)
            key = tuple(sorted(class_of[c] for c in vector))
            if key in seen or len(group(list(vector))) != len(G):
                continue
            seen.add(key)
            yield vector


def report(name, generators, orders):
    """Print one line for each different outcome among the refined passports."""
    seen = set()
    for vector in generating_vectors(generators, orders):
        r = check(vector)
        line = (f"{name}, signature {orders}: genus {r['genus']}, A = {r['A']}, B = {r['B']}, "
                f"non-hyperelliptic {'proved' if r['nonhyp'] else 'not decided'}")
        if line not in seen:
            seen.add(line)
            print(line)


if __name__ == "__main__":
    C = lambda n: [cycles(n, tuple(range(n)))]
    report("C_9   (y^3 = x^4 + x)", C(9), (3, 9, 9))
    report("C_15  (y^3 = x^5 + 1)", C(15), (3, 5, 15))
    report("C_3   (Picard curves)", C(3), (3, 3, 3, 3, 3))
    report("S_5   (Bring's curve)", [cycles(5, (0, 1)), cycles(5, (0, 1, 2, 3, 4))], (2, 4, 5))
    report("D_12  (genus 6 family)", [cycles(12, tuple(range(12))), tuple((-i) % 12 for i in range(12))], (2, 2, 3, 4))

Things to keep in mind

  • For a given group and signature, the answer can depend on the choice of the generators $a_0, a_1, a_\infty$, so check each choice.
  • A non-zero answer for a subgroup of $\mathrm{Aut}(C)$ proves nothing. Use the full automorphism group.
